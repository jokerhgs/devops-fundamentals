# DevOps Fundamentals Guide

Welcome to the **DevOps Fundamentals** repository. This project is a curated collection of reference guides, cheatsheets, and practical configurations for essential DevOps tools and methodologies.

The repository is structured using a branch-per-topic model, allowing for a focused and modular exploration of each technology.

## Table of Contents

1.  **[Docker](https://github.com/jokerhgs/devops-fundamentals/tree/docker)** – Fundamental containerization concepts, CLI commands, and image optimization techniques.
2.  **[Docker Compose](https://github.com/jokerhgs/devops-fundamentals/tree/docker-compose)** – Multi-container orchestration, networking, and environment management.
3.  **[Terraform](https://github.com/jokerhgs/devops-fundamentals/tree/terraform)** – Infrastructure as Code (IaC) principles, resource provisioning, and state management.

---

### Exploration Guide

To explore a specific technology, switch to its dedicated branch. Each branch includes relevant configuration files, scripts, and a specialized README detailing best practices and usage.

```bash
# Example: Switching to the Terraform branch
git checkout terraform
```
