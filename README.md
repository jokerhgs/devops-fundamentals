# DevOps Fundamentals Cheatsheet

Welcome to the **DevOps Fundamentals** repository! This project serves as a comprehensive cheatsheet and reference guide for core DevOps tools and practices, organized by branches for ease of exploration.

### How to use this repository

Each branch contains specific configurations and documentation for the respective technology. You can switch between branches to see the relevant files and READMEs for each topic.

```bash
# Example: Switching to the Docker branch
git checkout docker
```
